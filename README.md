# Bug Bounty Command Generator

A modern, dark-themed web application that generates ready-to-use reconnaissance commands for authorized bug bounty testing. Enter a target domain and copy commands for popular tools.

**Live site:** [hacktivist.app](https://hacktivist.app)

## 🚀 Features

- **Instant generation:** Commands update as you enter a domain.
- **One-click copy:** Copy a single command or the complete set.
- **Practical toolset:** Pre-configured commands for common recon tools.

## 🛠️ Included Tools

- **Subfinder** — Passive subdomain enumeration
- **Amass** — Asset discovery
- **httpx** — HTTP probing
- **Nuclei** — Vulnerability scanning
- **GAU** — Historical URL collection
- **Katana** — Web crawling
- **Waybackurls** — Wayback Machine URLs
- **ffuf** — Content and parameter fuzzing
- **Nmap** — Network discovery

## 💻 Run Locally

```bash
git clone https://github.com/aniltadvi20/bb-command-helper.git
cd bb-command-helper
open index.html
```

## ⚠️ Authorization & Ethics

Use generated commands only against assets you are authorized to test. Always follow the target program's scope and rules of engagement.
